# Shade Mixer

Pick any paint shade (pastels, brights, earth tones, neutrals) and see which paints to mix, and how many parts of each.

- **Find a shade**: 150+ named shades, or choose any color with the picker.
- **Mixing lab**: add parts of each paint and watch the mixed color.
- **My paints**: tick the paints you own; recipes and the Mixing lab only use those.
- **Scan paints from a photo**: take or upload photos of unlabeled paints, tap each one, and the site reads its color (with white-paper color correction) and adds it to My paints. Photos never leave the device.
- **Projects**: paint-by-number projects with a no-printer guide (grid method, tracing from the screen). 10 starter drawings (including Adventure Time fan art) sorted by difficulty and number of paints, plus a generator that turns any picture into a detailed paint-by-number using colors you can mix. Includes numbers view, grid for any canvas size, tracing mode, downloads and saved pictures.

Mixing is simulated with spectral Kubelka-Munk pigment theory, so blue + yellow makes green like real paint. Plain HTML/CSS/JS, no build step.
