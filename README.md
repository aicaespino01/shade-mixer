# Shade Mixer

Pick any paint shade (pastels, brights, earth tones, neutrals) and see which paints to mix, and how many parts of each.

- **Find a shade**: 150+ named shades, or choose any color with the picker.
- **Mixing lab**: add parts of each paint and watch the mixed color.
- **My paints**: tick the paints you own; recipes only use those.

Mixing is simulated with spectral Kubelka-Munk pigment theory, so blue + yellow makes green like real paint. Plain HTML/CSS/JS, no build step.
